# 건축 법규 "이유" 보기 (대구)

건축학과 저학년이 건폐율·용적률·정북일조사선이 설계에 미치는 **이유**를 이해하도록 돕는 학습용 웹도구입니다. 대구 안에서만 동작합니다.

- 지도에서 내 땅(필지)을 고르거나 Rhino `.3dm` / DXF 파일을 올리면 대지면적·건축면적·정북 이격을 채워 줘요.
- 답이나 수정안은 알려 주지 않고, 어떤 규정 때문에 어느 부분이 얼마나 걸리는지(사실)와 이유·질문만 보여 줘요.
- 계산은 브라우저 안에서만 해요. 도면 파일은 어디로도 보내지 않아요. (지도를 쓸 때 클릭한 좌표와 검색어는 VWorld로 전송돼요.)

학습용·참고용이며 인허가 판정이 아닙니다. 실제 설계는 최신 법조문·지자체 조례·전문가 확인이 필요해요.
